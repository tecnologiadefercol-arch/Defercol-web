## Descripción

La manguera de PTFE serie X con malla de acero inoxidable 304 ofrece flexibilidad y compatibilidad química. Tamaños: 1/4 a 1 pulg, presiones: vacío a 3500 psig. Disponibles opciones personalizadas.

La serie X es una manguera con ánima lisa de PTFE altamente flexible que se utiliza habitualmente cuando se desea flexibilidad y compatibilidad química.

La serie X es una manguera con ánima lisa de PTFE altamente flexible, con una malla de acero inoxidable 304 que favorece la contención de la presión en la manguera. Esta manguera se utiliza habitualmente cuando se desea flexibilidad y compatibilidad química.

Un rango de tamaños de 1/4 a 1 pulgada, presiones de servicio de vacío a 240 bar (3500 psig) y una variedad de conexiones finales permiten a la manguera serie X satisfacer las necesidades de una amplia gama de sistemas. La malla de fibra está unida al ánima mediante un proceso patentado que soporta el ánima para que no se retuerza. Hay disponible un ánima opcional de PTFE rellena de carbono negro para las aplicaciones que requieren disipación estática. Hay disponibles ensamblajes personalizados con otras opciones, como cubiertas de manguera y etiquetas.
