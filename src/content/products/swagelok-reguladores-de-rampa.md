## Descripción

Regulador de presión para hidrógeno en estaciones de servicio, diseñado para un control de presión seguro y preciso.

Diseñado para utilizarse en las aplicaciones de estaciones de servicio de hidrógeno, este regulador de rampa está diseñado para gestionar cambios térmicos y de presión rápidos que pueden afectar a la integridad del sistema.

El regulador pilotado de media presión proporcional Swagelok® para aplicaciones en estaciones de servicio controla la presión durante el repostaje de vehículos de hidrógeno. Añadido a un controlador PID, puede comunicarse con la unidad dispensadora para conseguir el perfil/rampa de control de presión requerido. Su diseño patentado de conjunto extraíble permite realizar el mantenimiento sin necesidad de retirar el producto del sistema dispensador.
